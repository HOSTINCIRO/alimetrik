NOTA SOBRE LA BASE DE DATOS
---------------------------
El sistema es EMBEBIDO: guarda los datos en la memoria del propio equipo
(archivos binarios en /almacen), sin servidor MySQL. Para cumplir el
requisito académico se creó el MISMO modelo en MariaDB/MySQL y se
administró con phpMyAdmin: el archivo base-de-datos/esquema-mysql.sql
reproduce exactamente las cinco tablas, sus llaves y relaciones.

CÓMO ABRIR phpMyAdmin OTRA VEZ
------------------------------
  brew services start mariadb
  cd /tmp/pma && php -S 127.0.0.1:8098
  luego abrir  http://127.0.0.1:8098   (usuario alimetrik / alimetrik2026)
Para detenerlo:  brew services stop mariadb
